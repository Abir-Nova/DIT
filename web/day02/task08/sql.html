SQL (pronounced /ˌɛsˌkjuˈɛl/ S-Q-L; or alternatively as /ˈsiːkwəl/ ⓘ "sequel")[4][5] is a domain-specific language used to manage data, especially in a relational database management system (RDBMS). It is particularly useful in handling structured data, i.e., data incorporating relations among entities and variables.[6]

  • SQL is essential for working with relational databases.
  • It makes it possible to search and retrieve specific data.
  • SQL can be used to insert, modify, and delete data.
  • It provides commands for creating and modifying database structures.
  • SQL is widely used in web applications and business applications.
  • Its syntax is relatively simple and readable for beginners.

  1. Select data

    
                        SELECT *
                        FROM users;

  2. Insert data

    
                        INSERT INTO users (name, age)
                        VALUES ('Abir', 22);

  3. Update data

    
                        UPDATE users
                        SET age = 23
                        WHERE name = 'Abir';

  4. Delete data

    
                        DELETE FROM users
                        WHERE name = 'Abir';

  5. Filter data

    
                        SELECT name, age
                        FROM users
                        WHERE age >= 18;

  6. Create a table

    
                        CREATE TABLE users (
                            id INT PRIMARY KEY,
                            name VARCHAR(100),
                            age INT
                        );
